# Spark1017 v0.2.0-alpha.1

Source alpha for DeepSeek-V4.1-Flash-1017 EXL3 2.9 bpw on two DGX Spark / GB10 hosts.

Includes repeated-code proposals, an experimental RDMA/HC fusion profile,
row-tiled Engram reduction, two-node build/start/stop/recovery scripts, and
English/Chinese deployment documentation.

## Checks

- Matching no-cache application image and fresh native compilation on both hosts.
- Nine Engram CUDA checks per GB10; representative extra peak allocation reduced from 600 MiB to 132 MiB.
- Three-profile diagnostic with existing rank caches: 58 matched complete requests per profile and 836 edit assertions. Its runtime source hashes and installed Python versions match the cold image.
- Local Linux CI and GitHub Python 3.11/3.12 CPU checks passed.
- Original deployment restored and verified after testing.

## Known issue

The final image's cold deployment completed 55 requests before its second 128K
prefill failed on a 64 MiB FP4 quantization allocation. Full SciCode/CanItEdit
regression was not reached in that run. The failure and successful diagnostics
are recorded separately; full clean-deployment qualification remains incomplete.
