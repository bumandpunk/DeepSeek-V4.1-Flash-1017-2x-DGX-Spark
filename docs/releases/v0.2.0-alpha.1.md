# v0.2.0-alpha.1

Developer preview for two DGX Spark / GB10 hosts. Python package version: `0.2.0a1`.

This release adds a reproducible image build, isolated two-node lifecycle,
private snapshots and verified recovery, three explicit profiles, and CPU CI.
The edit and experimental transport routes remain independently selectable.

The first two rounds' performance results and exact measured source snapshots
remain under `results/2026-10-27/` and `results/2026-10-28/`. They are historical
measurements, not a new universal speed claim for this release. Release-validation
evidence will be added after the clean deployment and restoration pass completes.

Known boundaries: no standalone wheel, no bundled weights, no full-precision
original model benchmark, no all-workload advantage over Mia, no validated
lookup-plus-RDMA combination, and no production uptime guarantee. The 4090 is
a client/CI/isolated-grading host; remote drafting is disabled.
